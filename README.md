# OmniRecon | All-in-One Domain & Infrastructure OSINT Hub

A serverless Open-Source Intelligence (OSINT) and passive domain reconnaissance dashboard designed for security analysts and defensive posture auditing. Ready for one-click deployment on **Vercel**.

## Features
- **DNS-over-HTTPS (DoH) Resolver**: Queries A, AAAA, MX, NS, and TXT records in real time.
- **HTTP Security Header Auditor**: Serverless function (/api/headers) inspecting HSTS, CSP, X-Frame-Options, Referrer-Policy, and server banners.
- **RDAP & Network ASN Intelligence**: Queries official IANA RDAP registries and IP ASN ownership.
- **Certificate Transparency (CT) Log Inspector**: Enumerates subdomains via crt.sh.
- **One-Click OSINT Pivot Matrix**: Deep-links for VirusTotal, Shodan, URLScan.io, Wayback Machine, SecurityTrails, Censys, BGP, SSL Labs, BuiltWith, and MXToolbox.
